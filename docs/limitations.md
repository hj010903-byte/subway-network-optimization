# Limitations

- GA: 계획만 확인, 교차·돌연변이·세대 반복 없음. 최종 최적해 검증 없음.
- 재현: 입력 Excel/CSV, 전처리 생성 과정, 난수 seed, 원래 환경 lock 없음. 저장 출력과 현재 source가 동일 실행인지 독립 검증 불가.
- 거리: 위경도 유클리드 값은 km가 아님. 발표의 2.5km 제한은 현재 제공 코드와 데이터만으로 검증 불가.
- A*: 비용에 0.1~1.9를 곱하면서 heuristic은 원래 좌표 거리라 과대평가 가능. 최단경로 보장 없음.
- 둔각: 실제 graph triangle 여부를 검사하지 않는 O(n³) 삼중쌍 처리. 대체 연결 및 연결성 보장 없음.
- coverage: 분모가 edge 그래프 노드임. 고립 역 또는 원본 역 목록 누락이 평가에서 사라질 수 있음.
- 후보: 셀 26은 탐색 실패 경로를 제외하므로 9개 노선 충족 보장 없음. 순환 역명이 edge ID와 맞지 않으면 2호선 경로가 비어 있을 수 있음.
- 점수: OD·시설 점수 반복 합산 가능. 실제 통행시간·건설 비용·운행 횟수·환승 부담에 대한 검증 없음.
- 개선: 셀 32의 미포함 노드 삽입은 기존 간선 여부를 확인하지 않음. 후속 개선은 graph에 새 간선을 추가하고, 탈락한 시도의 graph 변경도 되돌리지 않음. 길이·각도·간선 비중복 제약을 개선 후 재검증하지 않음.
- 현실성: 시각적 관찰을 바탕으로 한 판단이며 실제 공학적 운영 가능성의 입증이 아님.
- 기여·공개 권한: 개인 역할, 공동 저작자 동의, 데이터와 이미지 라이선스 확인 필요.
