# Methodology

전체 노선망 설계에는 역 coverage, 노선 수, 연결과 형태 제약을 함께 고려해야 합니다. Dijkstra/A*는 부분 경로 탐색 도구이며 네트워크 전체 구성을 직접 최적화하지 않습니다(발표 9~11장).

1. 좌표 수집·병합·중복 제거: 발표 12~14장에 설명, 실제 전처리 코드 없음.
2. 그래프 구성: 원본 셀 6의 KDTree 인접 연결과 셀 8의 Prim MST 비교. 경도·위도 평면 거리 사용.
3. 부분 경로 생성: 셀 14의 간선 소진·미방문 집합 관리, 셀 16의 BFS, 셀 18·20의 그룹화 실험.
4. 형태 개선: 셀 22의 모든 삼중쌍 둔각 판정과 최장변 제거. 발표는 삼각형을 설명하지만 실제 코드는 존재하는 세 간선을 요구하지 않음.
5. 후보 다양화: 셀 26의 coordinate_distance × Uniform(0.1, 1.9), 간선 재사용 금지 A* 변형.
6. 선별: |방문 역의 합집합| / |G_base 노드| × 100. 입력 역 목록 전체가 아닌 edge 그래프의 노드가 분모이므로 edge에 없는 고립 역은 분모에서 빠질 수 있음.
7. 추가 최적화 실험: 셀 30의 SA는 종합 점수와 확률적 수용을 사용. 셀 32는 작은 각도의 노드를 제거·재삽입하며 점수가 낮아지지 않을 때 유지.

셀 32의 종합 점수는 OD 기여 + 2.5×시설 점수 + 0.1×노선 길이 패널티 + 0.013×각도 패널티입니다. 길이는 거리 단위가 아닌 노드 수(20~50 범위)이며 순환 노선 ID 100은 길이 패널티에서 제외합니다. 각도 유효성 함수의 기본값은 35도입니다. 관련 주석의 60도와 다르며 개선 후보 추출에는 60도를 사용합니다. 시설 점수는 노선별 등장 횟수만큼 합산하고, OD는 각 노선 내부의 모든 역 쌍에 대해 합산하므로 중복될 수 있습니다.

GA의 초기 개체와 선별 전략은 있지만 유전 연산 및 세대 반복은 확인되지 않았습니다. 후반 두 최적화 방식을 GA라고 지칭하지 않습니다.
